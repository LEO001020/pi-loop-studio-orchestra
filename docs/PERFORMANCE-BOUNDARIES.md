# 性能与验证范围

两项真实任务均由本机配置的 Pi 模型端点完成，不是脚本替代模型；运行记录包含真实派发、用量、独立审核、文件发布和原生命令。不过它们跨越了本轮修订、检查点恢复与网络中断，不能声称是同一冻结版本连续无人干预的性能基准。

数值工具库任务 `3230e182-be8d-4815-8e67-e3ab76742564`：12 岗位，428 次模型调用，4,205,068 个提供方已报告 token，未知用量 0；12 岗位通过独立审核并发布，独立执行 106 项测试通过。成功执行请求在客户端的重叠峰值为 11（侦查与执行合计峰值 12）。

文本契约任务 `ab1edf8e-1b9f-4945-8344-b395eee83c5e`：12 岗位，482 次模型调用，4,728,237 个已报告 token，另有 8 次连接失败的用量未知。12 岗位通过独立审核并发布；测试数量与输出以总验收保存的原生命令回执为准。成功执行请求重叠峰值为 11。

这些数字说明流程能真实闭合，也说明小型任务上的推理与协调成本仍然显著。当前模型推理级别、上下文、输出长度及请求超时沿用本机配置，均可在 UI 调整；没有据此证明成本或延迟已最优。审核失败恢复复用固定提案、只读节点有限重试等修正有针对性的回归测试，但不能用测试替身推导未来真实任务的节省比例。

并发数指配置容量与成功请求的客户端在途时间重叠，不是提供方 GPU 同时执行数。依赖阻塞及任务尾部可能不足十个可运行工作项；不为凑数制造无用请求。硬性十路用量验收另由真实 budget-live 探针记录：全部执行请求成功、usage 可知、无预留，在途返回结算后阻止新增请求。

未验证：大样本真实项目成功率、24 小时持续运行、超大工作区吞吐、跨语言任意构建兼容性、总体返工率改善、全部候选架构的同机对照。数值库的历史仲裁还明确记录了一处 README 错误类型措辞冲突，不能将“106 项测试通过”理解为整个业务交付不存在任何缺陷。

历史失败保留在 validation；最终快照证据在 docs/verification，当前交付判断见 VERIFICATION.md 与 BLOCKED-UNVERIFIED.md。
